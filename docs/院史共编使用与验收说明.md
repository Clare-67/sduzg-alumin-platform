# 院史共编使用与验收说明

## 使用范围

院史共编仅向已登录校友开放。校友可以阅读已发布词条、提交新资料或补充现有词条；投稿不会直接改变正式内容，必须经管理员审核。

管理员只会看到其被授权培养类别内的待审投稿。平台沿用现有三类数据域：本科、学术学位研究生、MPA。超级管理员可查看全部领域。校友同时具有多个本院学习经历时，按最高学历所属培养类别确定投稿领域。

## 校友操作

1. 登录后进入“院史共编”，搜索或阅读正式词条。
2. 点击“参与编写”，填写标题、正文、资料来源和修改说明。
3. 可上传 JPG、PNG、WebP 或 PDF；单个文件不超过 10 MB，每次投稿最多 6 个。上传图片或扫描件时必须确认来源真实且有权提交。
4. 提交后在“我的投稿”查看草稿、待审、退回、已通过或驳回状态。被退回的投稿可补充后重新提交。

## 管理员审核

1. 进入“院史待审”，列表只展示当前管理员有权处理的领域投稿。
2. 打开投稿详情，核对正文、资料来源、附件说明及授权确认。
3. 选择通过、退回补充或驳回。退回与驳回必须填写处理说明。
4. 通过后内容才写入正式词条并生成版本；附件状态同步变为已通过。退回不会发布，投稿人可补充后再次提交；驳回不会发布。

## 安全与边界

- 不支持游客访问、管理员投稿、抢单、自动/手动分配或管理员直接编辑历史版本。
- 服务器对未登录、校友本人范围、管理员数据域和超级管理员全域分别校验；仅前端隐藏菜单不构成授权。
- 附件清单与下载地址同样受投稿所属领域限制。未授权管理员无法读取其他领域的投稿或附件。
- 文档和测试数据不得提交真实个人信息、密码、Token 或环境配置。

## 验收命令

```powershell
cd server; go test ./...
cd ../web; npm run lint; npm run test; npm run build
cd ../web; npm run test:e2e
cd ..; docker compose up --build
```

服务启动后，分别以三个培养类别校友、单域管理员、多域管理员、超级管理员和未登录状态验证：阅读范围、投稿状态流转、附件限制、领域隔离与审核结果。

`web/e2e/alumni-platform.spec.ts` 中的“校友可投稿院史资料，管理员审核后成为正式词条”会通过浏览器实际执行阅读、PDF 上传、提交、领域待审、审核通过和正式词条检索的完整流程。
